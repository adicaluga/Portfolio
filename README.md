# Adrian Calugarescu Tech Portfolio

A modern, responsive portfolio website built by Adrian Calugarescu as a Software Engineering student. This site showcases my background, technical skills, and projects with interactive elements and a professional design.

## Project Structure

```
portfolio/
├── public/                 # Static assets
├── src/                    # Application source
│   ├── components/         # Reusable UI components
│   ├── pages/              # Route-level pages
│   ├── assets/             # Images and local assets
│   └── main.tsx            # App entry point
├── index.html              # HTML template
├── tailwind.config.ts      # Tailwind configuration
├── vite.config.ts          # Vite configuration
└── README.md               # Project documentation
```

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui

## Development

Install dependencies and start the dev server:

```sh
pnpm install
pnpm dev
```

Build and preview:

```sh
pnpm build
pnpm preview
```
